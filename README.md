# gz-labs.github.io

The gz labs site, served by GitHub Pages at https://gz-labs.io. Each app gets a folder: `aepa/` is the support page (https://gz-labs.io/aepa/, the App Store support URL) and `aepa/privacy/` the privacy policy.

Plain HTML, no build step (`.nojekyll`). aepa's policy is generated from `PRIVACY.md` in gz-labs/first-words with pandoc; keep the two in sync.
