# gz-labs.github.io

The gz labs site, served by GitHub Pages at https://gz-labs.github.io. Each app gets a folder, for example `aepa/privacy/` is https://gz-labs.github.io/aepa/privacy/.

Plain HTML, no build step (`.nojekyll`). aepa's policy is generated from `PRIVACY.md` in gz-labs/first-words with pandoc; keep the two in sync.
